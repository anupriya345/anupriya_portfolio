# 2. Visual Design Direction

Use a **premium dark modern theme** with a sophisticated technology aesthetic.

### Color Palette

Primary:

* Deep navy / near-black background
* Electric blue
* Royal purple
* Subtle cyan accents
* White/light-gray typography

Use gradients carefully, especially:

* Blue → Purple
* Cyan → Blue
* Purple → Pink for very subtle highlights

Avoid excessive colors. The design should remain professional and clean.

### Design Style

Use:

* Modern glassmorphism cards
* Soft gradients
* Subtle glowing borders
* Large typography
* Rounded cards
* Minimal shadows
* Smooth hover effects
* Elegant micro-interactions
* Animated background particles/grid
* Gradient text for important headings
* Professional spacing and alignment

The website should look inspired by **modern SaaS, technology, AI, and developer portfolios**, while remaining unique.

Do not make it overly flashy.
